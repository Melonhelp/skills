# Melonhelp agent skills

Agent skills for AI coding agents (Claude Code, Cursor, Codex and any agent that reads `SKILL.md`) to install and work with [Melonhelp](https://melonhelp.com) products from inside your repository.

| Skill | What your agent can do with it |
|---|---|
| [melonhelp-feedback](skills/melonhelp-feedback/SKILL.md) | Add the [Melonhelp Feedback](https://melonhelp.com/feedback) button, public portal, satisfaction surveys and error reporting to a web app; identify users with a signed token; configure allowed origins, theme and widget; and fix the bugs and requests your users report. |

## Install

From this repository:

```bash
npx skills add Melonhelp/skills
```

Or straight from the product, which publishes its skill with Agent Skills Discovery:

```bash
npx skills add https://feedback.melonhelp.com
```

You can also copy the skill folder into your agent's skills directory by hand (for example `.claude/skills/melonhelp-feedback/` or `.cursor/skills/melonhelp-feedback/`).

## Works best with the MCP server

Each skill tells the agent to prefer the product's remote MCP server when it is connected. Melonhelp MCP servers use OAuth: paste the URL as a custom connector in your AI client, sign in in the browser and pick the workspace. No API keys, no local process.

| Product | MCP server |
|---|---|
| Melonhelp Feedback | `https://feedback.melonhelp.com/mcp` |

## Source of truth

The skills are generated by each product and served at `/.well-known/agent-skills/` (for example [feedback.melonhelp.com/.well-known/agent-skills/index.json](https://feedback.melonhelp.com/.well-known/agent-skills/index.json)). This repository mirrors them. If they differ, the version served by the product is the current one.
